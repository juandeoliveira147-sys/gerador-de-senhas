# Gerador de Senhas em Python

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da linguagem Python por meio da criação de um gerador de senhas seguras.

Durante o desenvolvimento foram aplicados conhecimentos como estruturas de repetição, funções, listas, tratamento de exceções, validação de dados, organização de código e utilização de bibliotecas da linguagem. Para a geração das senhas foi utilizada a biblioteca `secrets`, recomendada para a criação de senhas criptograficamente seguras.

## Funcionalidades

* Geração de senhas personalizadas.
* Definição do tamanho da senha (entre 8 e 128 caracteres).
* Opção de incluir:

  * Letras maiúsculas;
  * Números;
  * Símbolos especiais.
* Armazenamento das senhas geradas durante a execução do programa.
* Visualização das senhas salvas.
* Exclusão de senhas por índice.
* Validação de entradas para evitar erros de utilização.

## Tecnologias utilizadas

* Python
* Biblioteca `secrets`
* Biblioteca `string`
* Biblioteca `time`
* Biblioteca `sys`

## Objetivos de aprendizado

Este projeto foi desenvolvido para reforçar conhecimentos sobre:

* Organização de programas utilizando funções;
* Estruturas de repetição (`while`);
* Estruturas condicionais (`if`, `elif` e `else`);
* Tratamento de exceções com `try` e `except`;
* Manipulação de listas;
* Utilização da função `enumerate`;
* Validação de entradas do usuário;
* Uso de bibliotecas da linguagem Python.

## Observações

As senhas geradas permanecem armazenadas apenas durante a execução do programa. Ao encerrar a aplicação, todas as senhas são removidas da memória.

Este projeto faz parte da minha jornada de estudos em Python e representa mais um passo na evolução dos meus conhecimentos em programação.
